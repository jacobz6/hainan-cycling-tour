# 环海南岛骑行攻略 · 单文件 HTML（离线核心 + 联网增强）Spec

## Why
现有项目是"多文件 + Leaflet CDN + OSM 在线瓦片"的网页，传到 iPhone 后：无 CDN 无法加载地图库、无网时页面空壳；且行程用的是泛城市坐标（起点"海口市区"、终点"海口火车站"），与用户真实约束不符。需要按真实起点（9.26 11:00 CDF免税城·环岛旅游公路零点）、真实还车点（10.6 新埠岛西湾别墅店·517驿站，10 天租期不超时）、真实航班（10.6 17:40 美兰机场）重构行程，加入基于体能画像的每日计划与"计划被打乱可平移"的健壮性机制，最终产出一个**单文件 HTML**：核心计划内容无网也能完整查看，联网时功能健全（实时瓦片底图、实时天气等）。

## 已核实的关键事实（研究结论）
- **起点**：cdf海口国际免税城（秀英区海色路5号，`110.163029,20.048496`），即环岛旅游公路零点（新海港，2023-12-18 全线通车，主线 988km）。
- **还车点**："西湾别墅店" = **517户外自行车俱乐部(西湾别墅店)**，海口美兰区新埠岛西湾别墅（`110.362173,20.062409`，电话 0898-66217315 / 17789771517），全国连锁骑行驿站，提供租车/异地还车。
- **美兰机场**：`110.461273,19.942045`；新埠岛→美兰机场打车约 25-35 分钟。
- **高德 Key**：用户提供 `hainan_bicycle`，已验证 v3 place/text 与 v4 bicycling 均可用（infocode 10000）。
- **环岛旅游公路海口段**：新海港→滨海大道→世纪大桥→海甸岛→新埠路（新埠岛）→江东大道→海文大桥，约 60km。逆时针收官段（海文大桥→江东大道→新埠岛）天然经过还车点。

## 决策与假设（如与实际不符，请在审批时指出）
1. **骑行方向：逆时针（西进东出）**。理由：①11:00 从西侧零点出发直接向西出城，不用横穿市区；②还车点（新埠岛）与美兰机场都在海口东侧，逆时针收官段"海文大桥→江东大道→新埠岛"零回头路；③经典环岛走法。
2. **租期解读**：9.26 11:00 取车 + 10×24h → **10.6 11:00 前必须还车**（页面按"硬截止 10:30 到店"规划；若驿站按自然日计租，备选预案见健壮性模块：10.5 直骑至新埠岛还车、宿机场附近）。
3. **取车物流**：默认 9.26 上午完成取车（驿站送车至 CDF 免税城，或用户自取后骑至零点），11:00 从零点打卡出发。两种情形均写入提示。
4. **休整日固定 10.1（周四·国庆节）在三亚**：9.30 傍晚前抵达三亚，10.1 全天休整，10.2 出发。国庆黄金周住宿需提前预订（页面含提示）。
5. **体能画像**：31 岁男性，178cm/87kg，有健身及篮球基础但非骑行专项训练 → 按"载重旅行车均速 15-18km/h、日骑行 5-6.5h、日里程 70-115km"编排，支线彩蛋可选。
6. **联网架构**：单文件 HTML 内联全部核心资源（样式/脚本/数据/地图库），无网可看核心内容；瓦片底图与实时天气等仅在联网时加载/请求，断网时优雅降级（不报错、不空白）。
7. **高德 Key 用法（按用户明示提供）**：key 内嵌于 HTML 供联网功能使用（实时天气 v3 weatherInfo、必要时逆地理编码）；构建产物可联网调用。采集脚本同样用它做路径/POI 采集。已知风险（key 随文件分享会暴露、配额被消耗）在 README 中注明；如需更换可直接改 HTML 中 key 常量。

## What Changes
- **行程重构**：起点改为 CDF免税城零点（11:00 出发）；终点改为新埠岛西湾别墅517驿站（10.6 上午还车，11:00 前完成，10 天租期不超时）→ 美兰机场 17:40 航班；沿环岛旅游公路逆时针，全部过夜点改为滨海公路沿线城镇。
- **个性化每日计划**：按用户体能画像编排每日里程/配速/骑行时长/补给节奏，并明确"必达目标 + 可选彩蛋支线"两级结构。
- **健壮性模块（新增）**：进度闸门（每晚最晚位置检查点）、逐日 Plan B、"省里程开关"清单（跳过各彩蛋支线的节省公里数）、追赶合并方案、止损方案（环岛高铁/拼车/驿站救援）、台风应对规则。
- **BREAKING：架构替换**：多文件网页（index.html + app.js + style.css + data.js，Leaflet 走 CDN）→ **单文件 HTML**：Leaflet 库与全部样式/脚本/数据内联；核心内容（行程/轨迹/海岸线底图/健壮性/装备）零网络可看；瓦片底图、实时天气、定位增强仅联网启用。
- **联网增强（新增）**：①OSM 瓦片底图（在线时叠加）；②高德实时天气（当前+预报，沿途城市，localStorage 缓存供离线回看）；③浏览器定位"我的位置"（在线时显示位置与距下一目标距离）；④外链（台风网/驿站电话等，联网可用）。
- **数据管线 v2**：用用户提供的高德 key 重新采集：先 POI 定位全部途经点（含起点/还车点/机场），再分段链式调用 v4 骑行路径 API 沿旅游公路走廊取真实轨迹与里程。

## ADDED Requirements

### Requirement: 精确起终点与硬时限
系统 SHALL 在页面显著位置呈现并贯穿全篇三个硬约束：
1. 9.26（周六）11:00 从 cdf海口国际免税城（环岛旅游公路零点）出发；
2. 10.6（周二）上午骑至新埠岛·西湾别墅 517驿站还车，**11:00 前完成**（页面按 10:30 到店为硬截止），全程把握 10 天租期窗口不超时；
3. 10.6 17:40 美兰机场航班起飞（含值机截止与打车耗时提示）。

#### Scenario: 出发日
- **WHEN** 用户 9.26 11:00 在 CDF 免税城零点打卡出发
- **THEN** 页面 D1 卡片展示当日路线、目标里程与预计到达时间（半日骑行约 85km）

#### Scenario: 还车日时间线
- **WHEN** 用户查看 D11（10.6）
- **THEN** 页面展示完整时间线：铺前约 07:00 出发 → 海文大桥 → 江东大道 → 10:30 前到 517驿站还车 → 打车约 30 分钟至美兰机场 → 预留值机与航班 17:40 起飞；并标注"11:00 租期硬截止"

### Requirement: 基于体能画像的个性化每日计划
系统 SHALL 基于"31 岁 / 178cm / 87kg / 健身及篮球基础"设定配速与日里程（均速 15-18km/h、日骑行 5-6.5h、日里程 70-115km），每日计划包含：日期星期、A→B 路段、里程、预计骑行时长、地形与风向提示、补给点、食宿建议、当日"必达目标 + 可选彩蛋支线"。10.1（国庆）为三亚完整休整日。

#### Scenario: 强度适配
- **WHEN** 用户查看每日卡片
- **THEN** 西线（平坦）日里程 85-115km，东线（景区密集）日里程 70-90km，且体现实时"量力而行"提示（彩蛋支线可弃）

### Requirement: 健壮性机制（计划被打乱可丝滑平移）
系统 SHALL 提供结构化的健壮性模块：
1. **进度闸门表**：每晚最晚可接受位置（如 10.4 晚须 ≥ 文昌文城；10.5 晚距新埠岛 ≤ 50km）；
2. **逐日 Plan B**：每日卡片附"若今日未达 → 如何顺延/合并到明天"；
3. **省里程开关**：列出各可选支线的跳过节省量（如铜鼓岭 -32km、东郊椰林 -18km、南山 -12km 等）；
4. **止损方案**：环岛高铁（需打包，驿站可协助）/ 跨城拼车 / 517驿站救援电话；
5. **台风规则**：台风预警即停、就近城镇避险、闸门推算顺延。

#### Scenario: 落后半天
- **WHEN** 某日下午因天气或爆胎损失半天
- **THEN** 按当日 Plan B 弃彩蛋支线，晚间仍可回到主线，次日按闸门表正常衔接，后续日程无需整体改写

#### Scenario: 落后一天
- **WHEN** 10.4 晚仍在博鳌一带（落后约一天）
- **THEN** 健壮性模块给出追赶合并方案（如 D9+D10 合并）或止损方案（高铁/拼车直达海口），确保 10.6 硬时限不受影响

### Requirement: 单文件 HTML（离线核心 + 联网增强）
系统 SHALL 产出一个自包含 HTML（建议名 `index.html`，构建产物）：
- **核心离线可用**：样式、脚本、行程数据、地图库（Leaflet）、海岸线底图与环线轨迹全部内联，无任何网络也能完整浏览与交互（地图显示海岸线轮廓 + 逐日轨迹 + 标记）；
- **联网增强、断网优雅降级**：OSM 瓦片底图与实时天气仅在联网时加载，断网时不报错、核心内容不受影响；
- 文件目标 < 2.5MB（内联 Leaflet 后），可直接传输 iPhone 使用。

#### Scenario: 无网环境
- **WHEN** 用户在飞行模式 / 无网环境用浏览器（含 iPhone Safari）打开该文件
- **THEN** 行程卡片、健壮性模块、地图（海岸线+轨迹+标记+图例）、点日高亮等核心功能完整可用，页面无脚本报错

#### Scenario: 有网环境
- **WHEN** 用户联网打开该文件
- **THEN** 地图自动叠加瓦片底图；天气模块拉取沿途城市实时天气与预报；"我的位置"可显示当前位置与距下一目标距离

#### Scenario: iPhone 传输
- **WHEN** 用户按 README 指引操作
- **THEN** 可通过 AirDrop/文件 App 将单个 HTML 存入 iPhone 并查看（README 含步骤说明）

### Requirement: 地图（Leaflet 内联 + 瓦片在线叠加）
系统 SHALL 在单文件 HTML 内实现地图：
- Leaflet 库与样式内联（不走 CDN）；
- 常显图层（离线）：海南海岸线轮廓（内嵌简化 GeoJSON）+ 环线轨迹（高德 GCJ-02 → WGS-84 纠偏后按日分段配色）+ 关键点标记（起点零点、各过夜城镇、还车点、机场）+ 图例；
- 在线图层：OSM 瓦片（联网时叠加在海岸线之下/之上，按需自动尝试加载）；
- 交互：点击日期高亮对应分段并联动行程卡片，支持缩放平移。

#### Scenario: 地图交互
- **WHEN** 用户点击地图某日分段或图例
- **THEN** 该段轨迹高亮、其余段淡化，并定位/滚动到对应日程卡片

#### Scenario: 离线地图底线
- **WHEN** 无瓦片（断网）时查看地图
- **THEN** 海岸线轮廓与轨迹、标记仍完整可见可交互

### Requirement: 实时天气与联网信息（联网时）
系统 SHALL 提供联网增强模块：
1. **实时天气**：调用高德天气 API（内嵌用户 key），展示沿途主要城市（海口/临高/儋州/东方/乐东/三亚/陵水/万宁/琼海/文昌）当前天气与预报，结果缓存至 localStorage 供离线回看，并标注更新时间；
2. **我的位置**：浏览器定位 → 地图标记 + 计算距当日目标/下一过夜点距离；
3. **外部链接**：中央气象台台风网、驿站电话（tel: 链接）等；
4. 所有联网功能失败时静默降级，不影响核心内容。

#### Scenario: 出发前查天气
- **WHEN** 用户联网打开页面查看天气模块
- **THEN** 展示各沿途城市当前天气与未来数日预报；随后断网再打开仍可看到上次缓存的结果（标注"缓存于 X 时间"）

#### Scenario: 骑行中定位
- **WHEN** 用户联网点击"我的位置"
- **THEN** 地图定位当前位置并显示与当日目标的剩余距离

### Requirement: 数据采集管线 v2
采集脚本 SHALL 使用 `.env` 中的高德 key：v3 POI 检索定位全部途经点 → v4 骑行路径分段链式采集轨迹/里程/耗时 → 构建期完成坐标纠偏与抽稀。

#### Scenario: 采集校验
- **WHEN** 采集完成
- **THEN** 总里程落在 800-1000km、单日聚合里程 30-120km；轨迹沿海南海岸线走向，无穿海/内陆大跳跃
