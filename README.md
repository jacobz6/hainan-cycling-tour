# 环海南岛骑行计划 · 单文件 HTML（离线核心 + 联网增强）

**9.26（周六）11:00 CDF免税城·环岛旅游公路零点出发 → 10.6（周二）10:30 前新埠岛·西湾别墅 517驿站还车 → 美兰机场 17:40 起飞。**
逆时针西进东出，全程 995.9km / 骑行 10 天 / 三亚休整 1 天（10.1 国庆）。

## 使用（iPhone）

1. 把 `index.html` 传到 iPhone：**AirDrop**（选"文件"App 存储）或微信/网盘下载到"文件"App
2. 在"文件"App 中点开，选择 **Safari** 打开（建议"加入主屏幕"当 App 用）
3. **无网也完整可用**：行程卡片、地图（海岸线轮廓 + 逐日轨迹 + 标记 + 图例）、健壮性模块、装备贴士全部离线渲染
4. **联网时自动增强**：地图叠加高德瓦片底图；天气区拉取 11 个沿途城市实时天气 + 4 日预报（localStorage 缓存，断网回看）；"我的位置"按钮显示当前定位与距今日目标距离

## 单文件架构

```
开发源文件                          构建产物
├── template.html   # 页面骨架      ┌─────────────────────────┐
├── style.css       # 样式          │      index.html         │
├── app.js          # 渲染+地图逻辑  │  Leaflet(js/css) 内联     │
├── assemble.py  ──────────────────┤  样式/脚本 内联           │
│   （构建期：DP 抽稀、坐标舍入、    │  PLAN/ROUTES/COAST 内联  │
│     资源内联、占位符替换）         │  ~278KB 单文件           │
└──────────────────────────────  └─────────────────────────┘
```

- **坐标系**：全程 GCJ-02 不纠偏——轨迹（高德 API）、海岸线（DataV 省界）、在线瓦片（高德栅格瓦片）三者同坐标系天然对齐；仅浏览器定位（WGS-84）在前端转 GCJ-02 后打点
- **无外部依赖**：无 CDN、无外链 script/stylesheet、标记用 circleMarker/divIcon（无图片 404 风险）
- **联网功能全部静默降级**：断网无报错、不弹窗

## 数据管线（重新采集）

```bash
cp .env.example .env      # 填入你的高德 AMAP_KEY
python3 fetch_amap.py     # 40 个途经点 POI → data/geo_v2.json
python3 fetch_routes.py   # 分段链式 v4 骑行路径 → data/routes_v2.json（含逐日轨迹+备选线）
python3 make_coastline.py # 海南海岸线简化 GeoJSON → data/coastline.json
python3 assemble.py       # 内联构建 → index.html（打印大小与校验）
```

- `data/plan_v2.json`：手工编排的行程主数据（逐日配速/时间线/Plan B/闸门/装备/贴士），修改后重跑 `assemble.py` 即可生效
- 轨迹构建期 Douglas-Peucker 抽稀（容差 0.0004°）+ 5 位小数舍入：~24k 点 → ~1.6k 点，长度损失 <1%

## 高德 Key 说明

- 页面内嵌 key（用户提供，仅个人使用）用于联网天气与瓦片
- 更换 key：编辑 `data/plan_v2.json` → `meta.amap_key` → 重跑 `python3 assemble.py`
- 注意：key 会随 HTML 文件分发而暴露，且天气请求有 ~3次/秒 QPS 限制（页面已串行化处理）
